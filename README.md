## 👤 Tentang Saya

Saya developer yang fokus membuat **alat web praktis** dan **otomasi** untuk menyelesaikan pekerjaan berulang. Proyek-proyek saya berangkat dari kebutuhan nyata: mengonversi data, membuat metadata massal dengan bantuan AI, hingga menjalankan agen AI di Telegram dan Discord.

Prinsip kerja saya:

- **Sederhana dan fokus.** Satu alat untuk satu masalah, dengan antarmuka yang jelas.
- **Privasi dulu.** Sebisa mungkin proses berjalan di browser pengguna, tanpa server perantara dan tanpa pelacak.
- **Teruji dan terdokumentasi.** Logika inti diberi tes, dan setiap proyek punya panduan instalasi yang bisa diikuti.

## 🚀 Proyek Unggulan

### 🖼️ [StockMeta](https://github.com/akndrn000/stockmeta) · [Demo](https://stockmeta-one.vercel.app)
Generator metadata AI untuk kontributor **Adobe Stock** dan **Shutterstock**. Unggah hingga 20 foto per batch, lalu dapatkan judul/deskripsi, kata kunci, dan kategori. Hasilnya bisa disunting dan diekspor ke CSV sesuai format resmi tiap platform. API key disimpan di browser dan tidak pernah melewati server aplikasi.
`Next.js 16` `React 19` `TypeScript` `Tailwind CSS v4` `Vitest`

### ⚙️ [RigForge](https://github.com/akndrn000/rigforge) · [Demo](https://rigforge-lemon.vercel.app)
Konverter data avatar Roblox mentah menjadi script Lua untuk Roblox Studio. Semua proses berjalan di browser, tanpa server dan tanpa login. Logika konversi dilindungi 26 kasus uji snapshot.
`Vite` `React 19` `TypeScript` `Vitest`

### 📨 [Relay](https://github.com/akndrn000/relay) · [Demo](https://relay-eosin-five.vercel.app)
Web tool untuk mengirim pesan ke channel Discord melalui **Bot Discord resmi**, dengan pembatasan satu channel tujuan dan token yang tidak disimpan di server. Dirancang sesuai Ketentuan Layanan Discord.
`Next.js` `TypeScript` `Discord REST API`

### 🤖 [My Hermes Agent](https://github.com/akndrn000/my-hermes-agent)
Konfigurasi siap pakai untuk men-deploy **Hermes Agent** sebagai bot AI pribadi di **Telegram dan Discord** sekaligus, berbasis Docker dan Railway. Dilengkapi dokumentasi lengkap: instalasi, variabel lingkungan, troubleshooting, dan panduan keamanan.
`Docker` `Railway` `Telegram` `Discord`
